# WPageHeader

Cabecalho de pagina simples para titulo, subtitulo e acoes principais.

## API

<ApiTable name="WPageHeader" />

## Exemplo

```vue
<WPageHeader title="Alunos" subtitle="Gestao de alunos da academia">
  <template #actions>
    <Button label="Exportar" severity="secondary" />
  </template>
</WPageHeader>
```
