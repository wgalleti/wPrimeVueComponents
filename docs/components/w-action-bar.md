# WActionBar

Faixa flexivel para acoes principais, filtros e acoes secundarias.

## API

<ApiTable name="WActionBar" />

## Exemplo

```vue
<WActionBar>
  <template #primary>
    <Button label="Salvar e continuar" />
  </template>
  <template #secondary>
    <Button label="Cancelar" text />
  </template>
</WActionBar>
```
